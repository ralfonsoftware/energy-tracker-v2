Trend History — wide column + Meter Readings/Events entry grid

Updated 2026-09-28 from Ralf's live desktop review of the shipped page (fixed 660px column, squeezed chart, long single-column Meter Readings/Events lists). Supersedes the pre-2026-09-28 version of this file, which only ever showed the mobile/660px-column state.

What changed:
  • Column cap grows 660px → 900px ({spacing.content-max-wide}) on all four surfaces alike — one shared rule, not a Trend-History-only exception. {spacing.breakpoint-wide} (660px) is unchanged as the phone→wide trigger.
  • Trend chart gets the full wider column — same data, materially more drawing width.
  • Meter Readings and Events entries reflow into a fluid repeat(auto-fill, minmax(260px, 1fr)) tile grid — 2–3 columns depending on available width, never a fixed count. The card stack itself (chart → Meter Readings → Events → tree) still stacks one card per row; only the entries *inside* the two flat, independent lists gain columns.
  • The Room → Power Point → Device tree (hierarchical disclosure) is untouched — a grid doesn't fit a nested tree.
