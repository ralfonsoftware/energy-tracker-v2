Profile menu preferences — Language (FR-34) & Theme (FR-35)

Two compact icon strips join the Profile menu (≥660px), directly under the account email and above Profile / Log off. Below 660px there is no Profile menu, so the same two rows live in a Preferences card on Settings, next to Log off (decided 2026-09-30). Theme is System / Light / Dark as three icons; Language is the two launch Locales as two-letter codes DE / EN (flags are avoided — a language is not a country). Each row states its scope in one quiet line: Language changes the whole household, Theme only this device.

4 · Behavior spec (feeds Epic 8 stories)

  • Pattern. Preference icon strip: role="radiogroup" with role="radio" segments, roving tabindex — Tab enters the group on the checked segment, ←/→ (and ↑/↓) move and select, Home/End jump. Each segment has an accessible name (icons are never the only label); title shows the name on hover.
  • Size. Segment 44 × 40px visual, 44 × 44px hit area (row padding); strip radius 12px, segment radius 10px; row min-height 48px.
  • Order in the dropdown. Email → Appearance → Language → separator → Profile → Log off. Tab order follows reading order; Escape closes the menu and returns focus to the avatar button. Selecting a segment does not close the menu.
  • Theme (FR-35). Applies instantly, no request. Saved per device; applied before first paint. “System” follows the OS live; its accessible name includes the resolved value (“System — currently Dark”). Works offline.
  • Language (FR-34). Optimistic select → persist Household.Locale → on success switch UI language + number/date formatting together, without reload; a polite live region announces the change in the new language (“Sprache: Deutsch”). On failure, strip reverts and the inline error appears under the row; the language does not change. Other household members receive it on next load/session refresh.
  • Offline. Language strip disabled (server-persisted setting), sub-line becomes “Needs a connection” / “Benötigt eine Verbindung”. Theme unaffected.
  • Copy. New keys in both catalogs: appearance label + sub-line, theme option names, language label + sub-line, saving/error/offline strings. Deutsch / English are literal endonyms in both catalogs.
  • Below 660px. Same rows as a Preferences card in Settings › Account, above Log off. Not rendered at ≥660px (single owner per width).
