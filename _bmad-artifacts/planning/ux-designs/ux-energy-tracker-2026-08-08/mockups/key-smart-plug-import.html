Smart Plug Import — Key Screens

Five states of the same flow (FR-4, FR-24, Story 3.2), reached from Settings. State 1 shows the moment right after a file is selected — upload confirms immediately, parsing runs in the background, and the rest of the screen stays fully usable. State 2 shows a mid-range gap with prior history to average from, handled honestly rather than silently smoothed over. State 3 is the other load-bearing branch from parsing itself — the file's tag doesn't match any existing Power Point, so parsing pauses to ask rather than silently dropping or misfiling the data. States 4 and 5 (added this session) are FR-24's two remaining edge cases: a gap with nothing preceding it to average from, and an import that's entirely gaps.
