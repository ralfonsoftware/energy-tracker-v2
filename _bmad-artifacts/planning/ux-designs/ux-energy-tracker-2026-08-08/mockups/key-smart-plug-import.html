Smart Plug Import — Key Screens

Eight states of the same shared screen (FR-4, FR-24, FR-32, Story 3.2), now reached via icon entry points on both Dashboard and Trend History (no longer nested in Settings — see key-dashboard.html / key-trend-history.html). State 1 shows the moment right after a file is selected — upload confirms immediately, parsing runs in the background, and a live preview of the household's job history sits right below it on the same screen. State 2 shows a mid-range gap with prior history to average from, handled honestly rather than silently smoothed over. State 3 is the other load-bearing branch from parsing itself — the file's tag doesn't match any existing Power Point, so parsing pauses to ask rather than silently dropping or misfiling the data. States 4 and 5 are FR-24's two remaining edge cases: a gap with nothing preceding it to average from, and an import that's entirely gaps. States 6–8 (added 2026-08-26, the FR-4 amendment + new FR-32) cover multi-file queuing, the full six-state Job Status & History list, and its empty state.
