## Follow-up: OIDC callback URL scheme mismatch (2026-08-13)

- source_spec: none
  summary: Login against Auth0 fails with "Callback URL mismatch" — the app generates `redirect_uri=http://.../signin-oidc` (note `http`, not `https`), but Auth0 only has `https://.../signin-oidc` whitelisted.
